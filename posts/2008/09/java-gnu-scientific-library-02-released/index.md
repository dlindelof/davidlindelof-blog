I have released version 0.2 of the Java GNU Scientific Library (JGSL) project, its second public alpha release. Please visit the [JGSL project website](http://jgsl.sourceforge.net) for more information.

This second release provides additional wrapper classes for the GSL stats module (mean, variance, standard deviation, etc.). Feel free to try it out and get back to me for questions/comments.
