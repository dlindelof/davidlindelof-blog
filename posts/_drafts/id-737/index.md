_Little's Law_ states that for any stable system, the average arrival rate lambda, the average time spent in the system W and the average number of units in the system are related by L = lambda \* W.

If we consider EPFL as a reservoir of PhD students, then L is the number of PhD students in the system at any time and lambda is the number of new PhD students each year. If we further assume the system to be stable (which it isn't; the number of PhD students clearly increases over time. But this doesn't affect our main point.) then lambda is also the number of PhD students successfully completing their PhD (the number of PhD dropouts, although non-zero, is almost negligible).
