Do data scientists need to be good programmers? For that matter, do scientists need to be good programmers? My glib answer to that question will be, "Not unless they program." And by the way, writing scripts counts as programming. Writing formulas in Excel counts as programming. Performing any computation by the means of a computer counts as programming. I think you see where I'm going with this.

How does a scientist become a good programmer? I don't think there's a universal answer, and I can only tell what helped me become a better programmer. I draw most of my post-college education from books, and I would suggest that "Code Complete" is probably a suitable book, both for aspiring software engineers and for scientists willing to become better programmers. It's a hefty tome but will help you avoid many mistakes commonly found in analysis scripts, such as, well, an analysis script that does everything with no user defined functions, cryptically named variables, etc.

I was going to close this post on that, when I realized that there are two other fundamental skills that you need in order to effectively use a computer, besides strong programming skills. These are fundamental skills, yet I know of no educational system that teaches them.

The first is how to use a text editor. It seems obvious, but you will be spending your career writing code and writing articles, so you'd better invest in a tool that's designed for both. I don't care which text editor you're going to choose---choose one, and invest the necessary time to master it.

The second one is closely related to it, and closes the gap between the editor and the user. I'm referring to the mastery of touch-typing. You will spend your career banging on a keyboard, so it makes sense to learn how to do it effectively. Besides, some text editors (I'm looking at you, vi) are designed to be used by touch typists.

You don't need to reach professional typist levels, but...
